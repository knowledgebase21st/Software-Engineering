BubbleSort.java
 Demonstrates the Bubble Sort algorithm.
 Bubble Sort repeatedly compares adjacent elements and swaps them
 until the array is sorted.
 
 Time Complexity:
   Best Case    : O(n)
   Average Case : O(n²)
   Worst Case   : O(n²)
 Space Complexity:
   O(1)
